## Travail demandé (code)
1. **Types** : `Machine` gagne `marque?`, `modele?`, `garantie?`, `images?: string[]` (galerie, chemins sous `/public/machines/<slug>/`), et `prix` devient `"Sur devis" | number` (DH) ; un helper `formatPrix()` affiche « 17 000 DH » (espace fine insécable ou espace normale, cohérent). `specs` reste `Record<string,string>` mais l'ordre d'insertion est l'ordre d'affichage.
2. **Données** : ajouter les 9 machines dans `src/data/catalogue.ts` (bloc séparé « Machines en stock (catalogue V5) »), placées **avant** les fiches génériques dans la catégorie cardio. Ne pas supprimer les fiches génériques.
3. **Galerie** sur la fiche (`src/components/ProductGallery.tsx`, client) : grande image + vignettes cliquables, flèches clavier ←/→, `aria-current` sur la vignette active, compteur « 2 / 4 », `next/image` avec `sizes`, alt « <nom> – photo N ». Si `images` est vide : repli sur le `ProductVisual` actuel (aucune photo inventée). Prévoir un dossier `public/machines/<slug>/` avec un `.gitkeep` par machine et un `public/machines/README.md` qui explique le nommage (`1.webp`, `2.webp`…, 1600 px de large conseillé).
4. **Fiche technique** sur la page détail : tableau « Fiche technique » complet (toutes les specs, en 2 colonnes sur desktop), bloc « Marque / Modèle / État / Garantie », prix en DH, mention « Livraison gratuite à Casablanca · garantie 12 mois · installation possible ». Le message WhatsApp pré-rempli inclut marque + modèle + prix.
5. **Cartes produit** : afficher la marque (petit libellé) et le prix en DH quand il existe ; la première image de la galerie si présente, sinon le visuel actuel.
6. **Optimisation catalogue** : sur `/machines` et `/machines/cardio`, une section « En stock » qui met en avant les 9 machines réelles avant les fiches génériques ; filtre « Marque » (Matrix / Keiser / Technogym) dans les filtres existants (URL), avec test vitest.
7. **SEO** : `productJsonLd` ajoute `brand`, `model`, `image` (si présent), `itemCondition: RefurbishedCondition`, et `offers` (`price`, `priceCurrency: "MAD"`, `availability: InStock`) seulement quand le prix est un nombre. Métadonnées de la fiche : titre « Matrix T5x d'occasion révisée – 17 000 DH », description reprenant 2–3 specs clés.
8. `npm run lint`, `npx tsc --noEmit`, `npm test`, `npm run build` doivent passer.
